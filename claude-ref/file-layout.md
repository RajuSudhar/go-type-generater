# File Layout

Output file organization strategies. Source: `src/generator/go-generator.ts:398`.

## Grouping Strategies

Controlled by `-g, --grouping`:

| Strategy | Files | Categorization |
|---|---|---|
| `category` (default) | `models.go` · `enums.go` · `requests.go` · `responses.go` | schema.enum → `enum`; name has `request` → `request`; name has `response` → `response`; else → `model` |
| `single` | `types.go` | All types in one file |
| `custom` | Same as `category` | Placeholder — not yet differentiated |

## Always Emitted

| File | Content |
|---|---|
| `go.mod` | Module name from `--package-name`, Go 1.21, optional validator dep |
| `main.go` | Package declaration + export comments per type |

## Templates (`src/templates/go-templates.ts`)

| Template | Produces |
|---|---|
| `generateFileHeaderTemplate()` | `// Code generated by go-type-generator. DO NOT EDIT.` + timestamp |
| `generatePackageTemplate()` | `package X` + sorted imports |
| `generateStructTemplate()` | Struct def with embedded types + fields |
| `generateEnumTemplate()` | Type alias + `const (...)` block |
| `generateDecoderTemplate()` | `func parseX(raw interface{}) (*X, error)` wrapper |
| `generateGoModTemplate()` | `go.mod` with optional validator dep |

## Adding a Grouping Strategy

1. Extend `GeneratorOptions.grouping` union type
2. Add case in `organizeTypesIntoFiles()` at `go-generator.ts:398`
3. Update `categorizeType()` if new file-assignment logic needed
4. Add test in `tests/generator/go-generator.test.ts`
